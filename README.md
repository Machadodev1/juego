# BALA PERDIDA 🎯💥

Juego multijugador online de combate de tanques en laberintos 2D con física de rebotes.

## Estructura del Monorepo
- `/client`: Frontend en React + Vite + Tailwind CSS + PixiJS v8 + Colyseus.js.
- `/server`: Servidor autoritativo en Node.js + TypeScript + Colyseus + Matter.js.
- `/shared`: Contratos e interfaces TypeScript compartidas entre cliente y servidor.

## Ramas de Desarrollo
- `main`: Código estable e integrado.
- `feat/client`: Desarrollo del Frontend, renderizado 2D y cliente online.
- `feat/server`: Desarrollo del Backend autoritativo, físicas y generación de laberintos.
